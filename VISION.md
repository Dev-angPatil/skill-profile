# Vision - Skill Profile

## Core Problem
Traditional developer profiles and LinkedIn skills are unverified assertions without transparent calculation provenance. Developers lack a crisp, tamper-evident visual way to show *how* a skill score was achieved through real-world engineering actions.

## Target Experience
A clean, minimalist monochrome interface where developer skills are backed by verifiable event graphs. Hovering or clicking any skill box visually connects the skill to its contributing event nodes (PRs merged, incident postmortems resolved, benchmarks authored, and hackathons won) using clean animated SVG arrows and mathematical formulas.

## Success Criteria
- Crisp, high-contrast monochrome design (#fbfbfb paper tones, #09090b jet black).
- Seamless hover and click-to-pin interaction for skill calculation graphs.
- Clear event-level delta breakdown (e.g. Base + PR + Incident = Score).
- Zero bloat, responsive across desktop and mobile screens.
